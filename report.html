5. 通过率下降原因分析

重要说明

本次分析受限于可访问的数据表。生产环境的完整漏斗数据 (dw_advance_business_ekyc_transaction_funnel_detail) 位于 advance_sg 项目中，当前工作空间无访问权限。以下分析基于：

  • temp_ekyc_funnel_wide_table: 完整漏斗数据，覆盖 2025-01-21 至 2025-04-29
  • idv_aai_liveness_details: 活体检测明细，覆盖 2025-07 至 2026-04（采样数据）
  • 原因 1: 活体检测模型版本 / 策略变化
    从历史趋势看，liveness_started → liveness_passed 是通过率波动最大的步骤。Jan 2025 仅 77.93%，到 Mar 2025 提升至 91.82%（+13.89pp），说明此步骤受模型版本影响极大。若 Q4 2025→Q1 2026 间有模型版本回退或策略收紧，可直接导致 liveness pass rate 下降 ~5-10pp，进而影响整体通过率。建议检查 ensemble model 版本变更记录。
  • 原因 2: 人脸比对 (Face Similarity) 失败率上升
    Mar 2026 数据显示 SIMILARITY_FAILED = 4.75%（9,847 笔）。历史数据中 face_compare 步骤稳定在 ~94% 通过率。若该步骤通过率从 94% 降至 90% 左右，将贡献约 3-4pp 的整体通过率下降。可能原因：证件照片质量变化、比对阈值调整、或用户群体变化。
  • 原因 3: 前端漏斗转化率下降
    front_image_shown → front_scan_completed 从 Jan 的 91.0% 下降至 Apr 的 88.1%（-2.9pp）。这是 SDK 端的文档扫描步骤，可能受 SDK 版本更新、设备兼容性变化影响。全部为 PC/H5 流量，无移动端数据。
  • 原因 4: 流量结构 / customer_id 变化
    Mar 2026 出现新 customer_id 9929122076（207K PV），原 customer_id 9929123194 降至 4.5K PV。这种 customer 切换可能伴随着不同的产品配置（risk level、forgery threshold 等），导致通过率变化。建议确认 9929122076 的产品配置是否与 9929123194 一致。
  • 积极信号: Liveness 检测质量稳定
    Mar 2026 的 liveness pass rate = 97.8%，liveness_attack 仅 2.2%。说明活体检测环节本身表现良好。主要瓶颈在上游（前端漏斗）和下游（face comparison）。

SELECT
  SUBSTR(CAST(pt AS STRING), 1, 6) AS month,
  customer_id,
  SUM(is_front_image_shown)     AS front_shown,
  SUM(is_idv_passed)            AS idv_passed,
  COUNT(*)                       AS total_pv,
  ROUND(SUM(is_idv_passed) * 100.0
    / NULLIF(SUM(is_front_image_shown), 0), 2) AS pass_rate
FROM temp_ekyc_funnel_wide_table
WHERE region = 'MYS'
  AND customer_id = 9929123194
GROUP BY SUBSTR(CAST(pt AS STRING), 1, 6), customer_id
ORDER BY month;
