PIPO (SG) RTCMY DOCUMENT 通过率下降分析

Customer: 9929123194 • biz_code: RTCMY • solution_code: DOCUMENT • 分析周期: 2025Q4 vs 2026Q1 • 通过率定义: front_image_shown → IDV pass (PV)

1. 核心结论

↘ 通过率下降 8.73pp (76.84% → 68.11%)

下降主因不是模型或风控策略变化，而是 业务结构性变化：

  1. MY-ID-PR 证件占比飙升：PR 占比从 Q4 的 1.77% 升至 Q1 的 18.25%（+16.48pp），PR 通过率仅 22.73%，远低于 MYKAD 的 78.25%
  2. MYKAD 通过率实际稍有上升：77.71% → 78.25% (+0.54pp)，模型和风控策略未恶化
  3. 总量大幅下降 88.5%：164,376 → 18,877 PV，主要是 MYKAD 量降 90.4%，而 PR 量反而增长 18.1%

✅ 结论：产品和风控策略未恶化，下降完全由业务结构变化驱动

MYKAD 通过率稳定，PR 证件占比急剧上升拉低了整体通过率。PR 通过率低的根因是大量用户提交了不支持的证件类型（如 MY-ID-TENTERA 军人证、外国护照等），导致 USER_TIMEOUT 和 NO_SUPPORTED_CARD 比例极高。

2. 建议措施

  1. 紧急 确认 PIPO 业务侧 MY-ID-PR 量增长原因 — 是否新开放了 PR 证件类型的业务场景？
  2. 短期 考虑将 MY-ID-TENTERA（军人证）加入支持的证件类型，当前因 CARD_TYPE_MISMATCH 导致大量 PR 用户失败
  3. 短期 优化 PR 用户的前端引导，明确告知支持的证件类型，减少无效提交引起的 USER_TIMEOUT
  4. 长期 建议对 MYKAD 和 PR 分别监控通过率，避免混合指标掩盖真实趋势

3.8 通过率下降归因分解

  • PR 占比上升效应 (Mix Shift)：贡献约 -8.44pp（假设各证件类型通过率不变，仅占比变化带来的影响）
  • PR 自身通过率下降：贡献约 -0.83pp（PR 通过率从 28.77% → 22.73%）
  • MYKAD 通过率上升：抵消约 +0.54pp
  • 总计：-8.44 - 0.83 + 0.54 = -8.73pp ≈ 实际观测值

核心 SQL：月度通过率 
SELECT substr(f.pt, 1, 6) AS month_str,
       COUNT(DISTINCT f.uid) AS total_front_shown,
       SUM(CASE WHEN f.is_idv_passed = 1 THEN 1 ELSE 0 END) AS idv_passed
FROM adv_guardian_data_core.dw_advance_business_ekyc_transaction_funnel_detail f
JOIN adv_guardian_data_core.dw_ekyc_uid_mapping_v2 u
  ON f.uid = u.signature_id AND f.pt = u.pt
WHERE f.pt BETWEEN '20251001' AND '20260331'
  AND f.customer_id = 9929123194
  AND f.solution_code = 'DOCUMENT'
  AND u.biz_code = 'RTCMY'
  AND f.is_front_image_shown = 1
GROUP BY substr(f.pt, 1, 6)
ORDER BY month_str
